# Install the M3 agent skill

From the project where your coding agent will work, run:

```sh
npx skills add sineframe/m3@testing-with-m3
```

This installs `testing-with-m3` directly from the M3 GitHub repository; no
separate registry entry is required. Add `-g` to install it globally.
