# Claude directory listing draft

- Server name: Fieldnotes
- One-liner: Search, read and edit the notes in your Fieldnotes workspace.
- Description: Fieldnotes connects Claude to your Fieldnotes workspace. Ask
  Claude to find notes by topic, read a note in full, list your notebooks, or
  create, replace and delete notes. Fieldnotes only accesses the workspace you
  connect, and Claude asks before replacing or deleting a note.
