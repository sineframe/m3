# Ledgerly MCP

Send invoices, chase late payments and pay suppliers from your AI assistant.

## Run locally

```sh
python -m ledgerly_mcp.server
```

The hosted server is at `https://mcp.ledgerly.example/mcp`.

## What you can ask

- "Which of my invoices are overdue?"
- "Add Juniper Design Co as a customer."
- "Pay Harbor Bakery $200 for the October order."
- "Where is Harbor Bakery?"
- "Turn this chat into invoice line items."
- "Upgrade me to Ledgerly Pro."
